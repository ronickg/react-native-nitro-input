# NitroNumber props

`NitroNumber` accepts every `View` prop (`style`, `testID`, `accessibilityLabel`, …) plus the following. All are optional except `value`.

## Value and formatting

<Prop name="value" type="number">
The number to display. Every change rolls each digit natively. At most 18 digits are shown: `|value| × 10^fractionDigits` is clamped at 10^17, and a JS number carries exact integers only up to 2^53.
</Prop>

<Prop name="fractionDigits" type="number" default="0">
Digits after the decimal separator (0–9).
</Prop>

<Prop name="minimumIntegerDigits" type="number" default="1">
Zero-pads the integer part (1–15).
</Prop>

<Prop name="groupingSeparator" type="string" default="''">
Inserted every three integer digits.
</Prop>

<Prop name="decimalSeparator" type="string" default="'.'">
Between integer and fraction digits.
</Prop>

<Prop name="prefix, suffix" type="string" default="''">
Static text around the number.
</Prop>

## Roll timing

<Prop name="duration" type="number" default="500">
Roll duration in ms; `0` snaps.
</Prop>

<Prop name="easing" type="'linear' | 'easeIn' | 'easeOut' | 'easeInOut' | 'spring'" default="'easeInOut'">
Roll timing curve. A value that arrives mid-roll continues with the ease-out half of the curve, so rapid updates never stall.
</Prop>

<Prop name="bounce" type="number" default="0.15">
Overshoot of the `spring` easing (0–1).
</Prop>

<Prop name="stagger" type="number" default="0">
ms between the start of each digit's roll, least significant first (a cascading carry). In the numeric transition the cascade runs from the leftmost digit to the right instead; its default there is `50`.
</Prop>

<Prop name="transition" type="'roll' | 'numeric' | 'scramble'" default="'roll'">
How a value change plays; see [the transitions](/docs/nitro-number#transitions). `roll` is the odometer: every changed digit rolls through the digits between its old and new glyph. `numeric` is the effect of SwiftUI's `.contentTransition(.numericText())`: each changed glyph swaps in place, the old one softening, shrinking and sliding out while the new one slides in from the other side and comes into focus, the digits cascading from the left; unchanged digits stay put. `scramble` shows a different random digit every few frames until each changed digit locks on its target, from the left. Each swap style has its own defaults for `duration`, `easing` and `stagger`: numeric 480 ms with SwiftUI's own clocks (`easing` and `bounce` are not consulted) and a 150 ms cascade span as `stagger`, scramble 500 / `linear` / 60.
</Prop>

<Prop name="flashUpColor, flashDownColor" type="ColorValue">
The change flash: every digit whose glyph changes lights up in `flashUpColor` when the value grew and `flashDownColor` when it shrank (a green and a red, say), stays lit while it moves, and fades back over `flashDuration` once it has landed. Unset: no flash. Works with every transition, and under Reduce Motion, where the digits change at once but still light up.
</Prop>

<Prop name="flashDuration" type="number" default="600">
Milliseconds a change flash takes to fade, once the digit has landed.
</Prop>

<Prop name="popOnChange" type="number" default="0">
A punch of the whole figure on every value change, its peak overshoot as a fraction of the size, `0` (none) to `1`, rung out like the reveal's landing pop. `0.08` is a nudge, `0.2` a slam.
</Prop>

<Prop name="direction" type="'auto' | 'up' | 'down'" default="'auto'">
Roll direction; `auto` follows the sign of the change.
</Prop>

## Jackpot reveal

See [Jackpot reveal](/docs/loading-and-reveal#jackpot-reveal).

<Prop name="reveal" type="boolean">
`false` holds the opening frame (`$0.00` in the final layout); `true` plays the reveal to `value`. `undefined` = a normal rolling number.
</Prop>

<Prop name="revealStyle" type="'count' | 'spin'" default="'count'">
The win-meter rollup, or the slot reels locking from the left.
</Prop>

<Prop name="revealDuration" type="number" default="2200">
ms of the count, or until the last reel locks.
</Prop>

<Prop name="revealBounce" type="number" default="0.12">
Peak overshoot of the landing pop and the milestone punches; `0` = none.
</Prop>

<Prop name="revealGrow" type="number" default="0.2">
`count`: how much smaller the figure opens (a fraction of its size), growing to full size over the count.
</Prop>

<Prop name="revealStagger" type="number" default="200">
`spin`: ms between reel stops, shortened to fit the duration.
</Prop>

<Prop name="revealMilestones" type="number[]">
`count`: tiers in the figure's units. The count lands on each, punches, holds, then accelerates again.
</Prop>

<Prop name="revealMilestoneHold" type="number" default="0">
`count`: ms the count pauses on each milestone.
</Prop>

<Prop name="onRevealMilestone" type="(index, value) => void">
The count reached a milestone.
</Prop>

<Prop name="onRevealEnd" type="() => void">
The reveal landed (count or reels done, pop rung out).
</Prop>

## Loading

<Prop name="loading" type="boolean" default="false">
Shine glint: a slanted, text-wide band sweeps through the ink; cross-fades on toggle.
</Prop>

<Prop name="shimmerColor" type="ColorValue" default="light neutral">
Color of the glint's core (`#D6D9E1`, `#2B2E37` in dark mode).
</Prop>

<Prop name="shimmerDuration" type="number" default="950">
ms per sweep (linear, repeating).
</Prop>

## Typography and layout

<Prop name="fontSize" type="number" default="32">
Font size of the digits in points.
</Prop>

<Prop name="prefixFontSize, suffixFontSize" type="number" default="fontSize">
Smaller (or larger) prefix / suffix.
</Prop>

<Prop name="affixAlign" type="'baseline' | 'center' | 'top' | 'bottom'" default="'baseline'">
How prefix / suffix line up with the digits: `top` pins the glyph tops (cap height), `bottom` the bottom of the glyphs' ink (the digits' baseline).
</Prop>

<Prop name="prefixAlign, suffixAlign" type="'baseline' | 'center' | 'top' | 'bottom'" default="affixAlign">
Per-affix override.
</Prop>

<Prop name="adjustsFontSizeToFit" type="boolean" default="false">
Shrink the whole number to fit the view's width; the view keeps its full height.
</Prop>

<Prop name="minimumFontScale" type="number" default="0.5">
Lower bound for `adjustsFontSizeToFit`.
</Prop>

<Prop name="allowFontScaling" type="boolean" default="false">
Follow the system text size like `Text`.
</Prop>

<Prop name="maxFontSizeMultiplier" type="number" default="0">
Cap for `allowFontScaling`; `0` = no cap.
</Prop>

<Prop name="fontWeight" type="TextStyle['fontWeight']" default="'normal'">
Font weight.
</Prop>

<Prop name="fontFamily" type="string" default="system">
Font family, resolved like `Text`.
</Prop>

<Prop name="color" type="ColorValue" default="label color">
Text color.
</Prop>

<Prop name="textAlign" type="'auto' | 'left' | 'center' | 'right'" default="'auto'">
Alignment inside a wider frame. `'auto'` is the start edge of the layout direction, as `Text`, except in a view that hugs the number: there it is the edge the parent keeps the view to, so a figure at the end of a row (`justifyContent: 'space-between'`) grows and shrinks from its right edge instead of jumping. `'left'` and `'right'` are absolute. In a right-to-left app the prefix sits at the right edge and the suffix at the left, and the digits keep reading left to right; a single figure can be flipped with `style={{ direction: 'rtl' }}`.
</Prop>

<Prop name="onNativeRef" type="(ref) => void">
Receives the Nitro object on mount.
</Prop>

## Methods (`ref`)

| Method | Description |
| --- | --- |
| `animateTo(value)` | Rolls to `value`, like changing the prop. |
| `jumpTo(value)` | Positions the wheels continuously from `value` (odometer carry rule), no roll. Skips a running reveal. |
| `revealTo(value)` | Plays a jackpot reveal to `value` in the current `revealStyle`. |
| `getValue()` | The value shown or being rolled towards. |
| `native` | The Nitro object, or `null` before mount. |

All methods are safe to call from any thread and coalesce to the newest value per frame.
