`variant` draws a frame for the field, with a label that floats onto the top edge when the field is focused or holds text. `"outlined"` strokes the box and opens a notch for the label. `"filled"` gives it a `fillColor` background with a square bottom and an indicator rule along it. The default, `"none"`, draws nothing, and the field is styled the way a `TextInput` is, through `style`.

## Why it is native

Built in React Native, a floating label is an `Animated.Text` laid over a `TextInput`, moved from focus and text state that reach JS after the field has already changed. It lands a frame late, it stutters when the JS thread is busy, and its notch is a strip of background colour painted over the border. Here the label, the notch and the stroke all animate inside the view, off the native focus callback: nothing crosses into JS per frame, and nothing waits for a render.

## The notch

When the label floats, the outline opens a gap for it. The gap is a **real hole in the stroked path**, not a patch of background painted over the line, so whatever is behind the field shows through it: a photo, a gradient, a card of another colour. No Skia and no masking. The geometry is shared C++ (`OutlineGeometry`) that both platforms replay as the same move, line and arc commands, and every path has the same verbs at every progress, so Core Animation and `ValueAnimator` can interpolate between them.

## The label

`label` floats on focus or while the field has text, and `labelBehavior="always"` keeps it floated even when the field is empty and blurred. It is drawn at `labelFontSize` (default three quarters of `fontSize`) in `labelColor`, switching to `labelFocusedColor` while focused; those default to the placeholder colour and to `focusedStrokeColor`. A label also becomes the field's accessible name when nothing else gives it one. It sits at the start edge, so in a right-to-left layout it floats from the right and the notch opens there.

The label runs 200 ms on a decelerate curve, and the notch is staggered 50 ms behind it opening and closes in 50 ms, so the gap is never open under a label that has not arrived. All of it runs inside the view, off a native focus callback. There is no React state to declare and nothing crosses into JS per frame.

## Stroke, fill and corners

| Prop | Default | |
| --- | --- | --- |
| `strokeColor`, `focusedStrokeColor` | separator colour, `strokeColor` | The outline. Named `stroke*` rather than `outline*`: React Native 0.76 gave every view a CSS `outlineColor`, and a Hybrid View's props derive from `ViewProps`, so both parsers would run. |
| `strokeWidth` | `1` | Doubles while focused. |
| `cornerRadius` | `8` | Clamped to half the shorter side. `filled` squares its bottom so the indicator meets the fill. |
| `fillColor` | secondary fill | The `filled` background. |

A frame does not change what the field is. Formatting, masking, a [multiline](/input/multiline) field and the [morph](/input/morph) all work inside one.
