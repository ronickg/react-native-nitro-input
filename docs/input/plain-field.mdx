title: A plain field
description: 'NitroInput without the morph: a native single-line input that costs no more to mount than a bare UITextField.'
---

`NitroInput` is the same component without the morph: the system field draws
its own text, so there is no glyph engine, no per-glyph layers and no custom
caret. Everything else is identical — `'number'` formatting, the focus path,
React Native's text-input registry and keyboard-controller support.

```tsx
import { NitroInput } from 'react-native-nitro-input'

<NitroInput
  placeholder="Email"
  keyboardType="email-address"
  textContentType="username"
  style={{ height: 52, width: '100%' }}
/>
```

It takes every `MorphInput` prop except the morph ones (`duration`, `easing`,
`bounce`, `effect`).
