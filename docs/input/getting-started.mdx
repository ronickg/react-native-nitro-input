# Getting started

`react-native-nitro-input` is a **native text input** for React Native, built with [Nitro Modules](https://nitro.margelo.com). `NitroInput` is the component: a system text field (`UITextField` / `EditText`) that owns the keyboard, editing, selection, paste and accessibility, with native amount formatting, native masking, and an outlined or filled frame with a floating label, all done on the native side.

Nothing animates unless you ask. The field draws its text the instant you type it, the way a `TextInput` does. The [reflow](/input/reflow), which makes characters glide and digits roll, is an effect you turn on for the one screen where it is the point.

## Requirements

- React Native **0.78+** with the new architecture (Fabric) enabled.
- `react-native-nitro-modules` **0.37+**.
- The iOS and Android minimums are React Native's own; the package adds none.
- `react-native-worklets` is optional, and only for the [worklet props](/input/worklets).

## Install

```bash
bun add react-native-nitro-input react-native-nitro-modules
```

```bash
cd ios && pod install
```

With Expo, add both packages, then run `npx expo prebuild` (or a dev client build). Nothing else to configure: the view autolinks through Nitro on both platforms.

:::warning Android and Nitro 0.37

Nitro never hands a Hybrid View its `backgroundColor`, `border*`, `opacity`, `transform`, `testID` or accessibility props on Android with React Native 0.86+, so the `style` on the examples below is silently dropped there while working on iOS. Fixed upstream in [margelo/nitro#1655](https://github.com/margelo/nitro/pull/1655); until it ships, apply the [patch from this repository](https://github.com/ronickg/react-native-nitro-rolling-number/blob/main/patches/react-native-nitro-modules@0.37.1.patch) with `patchedDependencies` (Bun) or patch-package.

:::

## First field

```tsx
import { NitroInput } from 'react-native-nitro-input'

<NitroInput
  placeholder="Your name"
  autoCapitalize="words"
  returnKeyType="done"
  onSubmitEditing={({ text }) => save(text)}
  style={{ width: '100%', height: 44, paddingHorizontal: 12, backgroundColor: '#F2F2F7', borderRadius: 10 }}
/>
```

It takes `TextInput`'s props: keyboard types, the return key, auto-capitalisation, `maxLength`, `secureTextEntry`, `selection` and the edit callbacks. It sits in React Native's text-input registry, so `Keyboard.dismiss()`, `keyboardShouldPersistTaps` and keyboard-controller treat it as the text input it is. Like a `TextInput`, it takes its width from its parent.

## An amount

```tsx
const [amount, setAmount] = useState(NaN)

<NitroInput
  mode="number"
  prefix="$"
  fractionDigits={2}
  placeholder="0"
  fontSize={32}
  fontWeight="700"
  style={{ width: '100%' }}
  onChangeValue={setAmount}   // 1234.5, or NaN while empty
/>
```

Type `1234` and the field shows `$1,234`: the formatter runs in C++ on the keystroke, before the field draws, so the comma arrives in the same frame as the digit that displaced it. `onChangeValue` hands you the number, `onChangeText` the formatted string. Nothing here animates. Add `transition="reflow"` when you want the comma to slide into place rather than appear there.

## A frame

```tsx
<NitroInput
  variant="outlined"
  label="Email address"
  keyboardType="email-address"
  style={{ width: '100%', height: 52 }}
/>
```

The label floats onto the top edge on focus and the outline opens a real notch for it, inside the view rather than with an animated label over a `TextInput`. [Frames](/input/frames) has the rest.
