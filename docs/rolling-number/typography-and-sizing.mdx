## Typography

`fontSize`, `fontWeight`, `fontFamily` and `color` work like `Text`'s style props. Bundled fonts resolve the way they do for `Text` (by PostScript or family name on iOS, through React Native's font manager on Android, including fonts registered with `expo-font`). Digits always use tabular figures so every column has the same width.

`allowFontScaling` follows the system text size like `Text`, capped by `maxFontSizeMultiplier`. It is **off** by default so amounts keep their design size.


## Sizing

The view reports its intrinsic size from native and sizes itself. When a digit column appears the box grows right away (the view is not clipped, so nothing is ever cut off); when the settled number is narrower the box shrinks only after the roll has finished, so digits on their way out are never squeezed.

Give it an explicit `width` in `style`, plus `textAlign="right"` (or `"center"`), if you don't want the layout around it to reflow as digits appear, a counter that grows past `999` for instance:

```tsx
<RollingNumber value={count} textAlign="right" style={{ width: 120 }} />
```
